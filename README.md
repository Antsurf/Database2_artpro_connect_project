# Database2_artpro_connect_project

## Group 2: 
- Antoine Richard
- Jérémy Sagnard
- Rémi Pyt
- Matthieu Sirier

This project aims to give you the opportunity to design and implement  a relational database, then integrate it into an existing Java application (provided  as a skeleton). You will need to design the database, implement it in MySQL, and  progressively replace the in-memory services with a real persistence layer (entities,  DAO, services).
